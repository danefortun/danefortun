# Hey, I'm Dane 👋

## About Me

I'm a senior at Drexel University studying Computer Information and Security, with a concentration in Computing Security. I transferred from Northampton Community College, where I graduated with honors in 2025.

I currently work as a full-stack developer at Intealth, contributing to production applications, automated testing, and security research for agentic AI. Front-end development got me into programming, and I still enjoy building interfaces that are useful and easy to navigate. I'm just as interested in understanding the back end and making the whole application more secure.
